# Movie-Sentiment 🎬
Text Cleaning: Preprocess and normalize text.
Data Visualization: Explore sentiment distribution and word patterns.
Modeling: Four ML models for sentiment prediction.
Evaluation: Metrics like Accuracy and F1-Score to compare models.
Application: Ready-to-use interface to predict sentiment from new text.
Technologies: Python, Pandas, Numpy, Matplotlib,Scikit-learn, NLTK, Streamlit.
